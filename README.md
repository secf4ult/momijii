# モミジイ · Momijii

日本全国红叶旅行清单与地图。Next.js + TypeScript + Leaflet + OpenStreetMap，无地图 API Key。支持静态部署到 GitHub Pages，并提供中日文轻量密码入口。

## 启动

```bash
cd ~/Projects/momiji-checklist
npm install
npm run dev
```

访问 http://127.0.0.1:3000 。服务仅监听本机。

```bash
npm run build               # 静态导出到 out/，默认根路径
npm start                   # Python 3 本机静态预览，端口 3000
npm run typecheck
npm test
npx playwright install chromium
npx playwright test          # 先启动开发服务；含密码入口、中日文及清单测试
```

## GitHub Pages 部署

仓库：https://github.com/secf4ult/momijii

站点地址：https://secf4ult.github.io/momijii/

`.github/workflows/pages.yml` 在推送 `main` 或手动运行时安装依赖、执行单元测试、静态构建并部署 `out/`。仓库 Settings → Pages → Build and deployment 的 Source 应选择 **GitHub Actions**。工作流设置 `NEXT_PUBLIC_BASE_PATH=/momijii`，确保 JS、CSS 和首页链接在项目子路径下正常工作。未设置变量时，本地开发及静态构建使用根路径。

手动生成与 Pages 相同的产物：

```bash
NEXT_PUBLIC_BASE_PATH=/momijii npm run build
```

更新景点数据需要在本地运行采集脚本、提交 `data/spots.json` 并推送，触发重新构建。Pages 不运行采集程序或 Node.js 服务，季节颜色则始终在浏览器中按当前日本日期计算。部署后不会自动迁移本机浏览器的笔记；上线域名是新的 origin，请先导出备份（当前无图形化导入）。

## 轻量密码入口

默认密码：`momiji`。新标签页打开网站时显示密码表单，输入正确后显示页面；刷新会保留当前标签页会话。页头锁形按钮可立即重新锁定，且不删除清单和笔记。语言切换在密码页也可用。浏览器禁用存储时，输入正确密码仍可访问，但刷新后需重新输入。

**这不是安全认证、HTTP Basic Auth 或加密。密码存在前端代码中，静态 HTML/RSC/JS 及景点数据可被下载检查；公开仓库中的源码和数据同样可见。不要将敏感信息、个人笔记、密钥放入仓库。轻量密码也不能替代来源数据授权。**

修改密码：编辑 `lib/access.mjs` 的校验值并重新部署；如需让现有会话失效，同时修改 `ACCESS_SESSION_KEY` 的版本。解锁标记只存在 sessionStorage，实际密码不会存入浏览器存储或发送到后端。搜索引擎 `noindex` 仅是提示，不是访问控制。

## 界面语言

页头可选择「简体中文 / 日本語」。默认中文，语言偏好保存在独立的 `momiji-language-v1` localStorage 项中，刷新后恢复，同源标签页同步；存储不可用时仍可在当前页面切换。

切换不刷新页面，不清空筛选、日期、笔记或旅行状态。界面、提示、地图图例/弹窗/无障碍标签、页面标题和 HTML `lang` 随语言更新。景点名称、来源时间原文、用户笔记保持不变，状态 ID 和导出数据结构不变；底图地名由 OpenStreetMap 瓦片提供，不随界面语言切换。

翻译字典：`lib/i18n.mjs`；上下文和切换器：`components/LanguageProvider.tsx`。浏览器日期输入控件自身的日期格式由浏览器/系统决定，季节判断始终使用日本日期。

## 全站目录与地区分类

以 https://koyo.walkerplus.com/sitemap_detail.xml 的全部独立名所页为覆盖基准，并用全站都道府县列表和分页提取结构化事实。当前索引 1,198 处，覆盖 46 个都道府县；来源未列出冲绳名所，不伪造记录来凑齐 47 县。

- 都道府县 → 市区町村联动筛选；政令市按市归类，同时保留原始区信息。
- 保留县名、原始所在地、市区町村、例年见顷原文、开始变色时间、来源 URL、每条采集时间和坐标来源时间。
- 郡名保留在原始所在地，町村按本名归类；如「利根郡みなかみ町 → みなかみ町」。
- 地区汇总可按县钻取到市，显示景点数量、观赏期跨度、各季节状态的景点数。
- **地区时间跨度是各景点最早开始到最晚结束的并集边界，不是整个地区持续盛开。**
- 每页 24 处景点；地图显示全部筛选结果，使用聚合标记与 Canvas 圆点，聚合数字为景点数，不是排名。
- 旅行清单「未去过 / 准备去 / 已去过」、日期、笔记与季节状态相互独立，原有 localStorage 记录继续按景点 ID 关联。

## 季节颜色规则

页面按 **Asia/Tokyo 日本当地日期** 判断，每分钟检查跨日。可通过日期控件预览其他日期，点击「回到今天」恢复自动日期。颜色用于卡片与地图：

| 颜色 | 状态 | 规则 |
| --- | --- | --- |
| 灰 | 未到观赏季 | 距预计开始超过 14 天 |
| 绿 | 即将到来 | 开始前 14 天（含）至前一天 |
| 红 | 盛开季节 | 开始到结束，两端含当天 |
| 黄 | 已过盛开季节 | 结束后 |
| 紫灰 | 时间待确认 | 来源缺失、含歧义或无法可靠解析 |

上旬 / 中旬 / 下旬按 1–10 / 11–20 / 21–月末估算，「初旬」按上旬处理，支持「11月上旬～中旬」这样的省略月份。例年区间按查看年份计算，常规秋季区间每年 1 月重置为新一年的预测；跨年区间在次年 1 月仍有效。

来源明确指定年份的期间标记 `periodKind: dated`，只在原始年份生效，日期取与原文年份匹配的结构化起止日期（不会将 2025 年特别公开期套用为 2026 年）。这些可能是特别开放期，并不保证整个开放期间红叶正盛。其他区间标记 `typical`，只根据例年见顷原文推算，**不直接把所有活动/入场日期当成最佳观赏期**。

多段草红叶 / 树木区间、混有其他运营日期等无法可靠解析的文本原样保留，显示「时间待确认」。季节颜色都是估计，不代表实时观测。请出发前查看来源；红叶并非花卉，「盛开季节」沿用需求中的状态名称。

## 全量采集与数据文件

```bash
npm run sync                # 默认复用本地缓存，失败后可续跑
npm run sync -- --skip-maps  # 只更新全量目录
npm run sync -- --refresh    # 重新向来源取数，仍然限速
```

采集单进程串行，请求开始至少间隔 1.2 秒；25 秒超时、最多 3 次重试、退避等待。遇 403 / 429 立即停止，不绕过访问限制。运行前检查 robots.txt；若包含限制则停止待人工审查。使用锁文件避免同时运行，每 10 页原子更新快照与报告。网页访问绝不触发采集。

列表阶段使用 190 个县市列表和分页核对全部 1,198 处，再逐个补充地图页坐标，可能需要约半小时。页面会明确显示已收录数、来源总数、坐标覆盖数和采集阶段；运行中刷新即可读取最新本地快照。无坐标的景点不会被放到虚构位置。

- `data/spots.json`：全部名所事实和覆盖统计（运行中持续更新）。
- `data/sync-report.json`：来源索引总数、缺失 URL、坐标覆盖和失败信息。
- `data/regions.json`：按县 → 市区町村分组的数量、时间跨度、季节统计及景点 ID（任务结束时导出）。
- `data/spots.csv`：可用 Excel 打开的 UTF-8 BOM 全量表（任务结束时导出）；季节列为导出当天快照。
- `data/.cache/`：本地私有原始响应及采集时间，已加入 gitignore，不得公开分发。

页面在构建时读取 `spots.json`；公开静态站点需要重新构建部署才能更新数据。若进程异常退出，先确认没有同步进程运行，再删除 `data/.sync.lock` 后重跑；不要在运行中删除锁或缓存。坐标可能指入口/代表点，不代表山顶或整条路线。

## 授权与地图

来源 https://koyo.walkerplus.com/ 。robots 允许抓取不等于授权。Walkerplus 使用条款 https://www.walkerplus.com/info/rules.html 限制私人使用；本项目不复制照片和介绍文案，卡片为原创 CSS 示意图。**公开部署、再分发快照或商业使用前需确认授权。**

地图使用 OpenStreetMap 数据与标准在线瓦片，保留署名，公共瓦片无 SLA，不得批量预取或离线下载。正式上线需按流量选择服务或自托管：

- https://www.openstreetmap.org/copyright
- https://operations.osmfoundation.org/policies/tiles/

不使用来源地图嵌入的 Google Maps API Key，不向地理编码服务发送请求。地图适配器为 `components/Map.tsx`，后续可以替换为 Google Maps，旅行记录和季节规则独立。

## 隐私与保存

记录只存在当前浏览器当前 origin，`127.0.0.1` 与 `localhost` 不共享。无账号、无跨设备同步；清理浏览器数据会丢失记录，请定期导出 JSON 备份，目前无图形化导入。其他同源标签页会在记录改变后自动刷新。

「我的位置」在授权后使用 Geolocation 持续更新，点击按钮或关闭地图停止跟踪。需要 localhost 或 HTTPS。位置不写入本地清单或项目后端。地图服务可收到 IP 及所请求瓦片范围，字体从 Google Fonts 加载。无业务分析追踪；Next.js 开发工具遥测可设置 `NEXT_TELEMETRY_DISABLED=1` 关闭。
